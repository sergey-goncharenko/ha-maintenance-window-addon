# Add-on artwork (placeholders)

Home Assistant displays two images for an add-on. Add these PNG files to this
folder before publishing:

- `icon.png` — square, recommended 128×128 px. Shown in the add-on list.
- `logo.png` — wider banner, recommended 250×100 px. Shown on the add-on page.

These are binary assets and are intentionally not generated by the scaffold.
Replace this file once you add real artwork.
