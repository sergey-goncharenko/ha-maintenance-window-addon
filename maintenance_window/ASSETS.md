# Add-on artwork

Home Assistant displays two images for an add-on:

- `icon.png` — square, recommended 128×128 px. Shown in the add-on list.
- `logo.png` — wider banner, recommended 250×100 px. Shown on the add-on page.

The current artwork is simple generated PNG art: a plain Home Assistant-style
home outline over a yellow/black maintenance tape pattern. Replace it later if
the add-on gets a more formal visual identity.
